# Maven Toys’ Store & Product Performance Dashboard

## by Lucila Aldana Quiñonez | Marketing Data Analyst

📄 Report available in: English - Spanish

This project develops an interactive retail performance dashboard for Maven Toys, a multi-location toy store chain, to provide visibility into revenue trends, store performance, product contribution, and inventory health across locations.

The objective was to transform transactional and inventory data (January 2022 – September 2023) into a centralized decision-support tool that enables leadership to monitor business health, identify growth opportunities, and optimize operational efficiency.

The dashboard analyzes:

• Total orders, revenue, profit, and average transaction value

• Revenue and sales trends over time with drill-down capability

• 30-day moving average to smooth short-term fluctuations

• Top-performing stores by revenue, profit, and orders

• Store age for lifecycle benchmarking

• Product category performance with drill-down to product level

• Top 5 best-performing and bottom 5 underperforming products

• Current stock levels and inventory coverage in days

• Stock health classification (Out of Stock, Critical, Low, Good)

Interactive slicers (year, quarter, month, store city, location type, and selected metrics) allow stakeholders to dynamically explore performance patterns and compare stores across regions and time periods.
Key insights supported by the dashboard include identifying seasonal trends, benchmarking mature versus newly opened stores, detecting declining product categories, and proactively managing stock risk through coverage analysis.

The project integrates sales performance, profitability tracking, and inventory monitoring into a single executive reporting system designed to improve operational visibility and strategic planning.

Tools Used: Power BI / Data Modeling / KPI Development / Retail Analytics / Inventory Analysis / Interactive Dashboard Design
